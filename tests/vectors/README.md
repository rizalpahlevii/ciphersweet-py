# Test vectors

| File | Source |
| --- | --- |
| `nacl.json`, `nist.json`, `boring.json` | Copied verbatim from [paragonie/ciphersweet](https://github.com/paragonie/ciphersweet) `tests/KnownAnswers/`. |
| `php_interop.json` | Generated by `generate_php_interop.php` with paragonie/ciphersweet v4 on PHP 8.3 (libsodium 1.0.18). |

To regenerate `php_interop.json` (ciphertexts change every run because nonces are random, every
other value is deterministic):

```sh
mkdir /tmp/csvec && cd /tmp/csvec
composer require paragonie/ciphersweet:^4
cp /path/to/ciphersweet-py/tests/vectors/generate_php_interop.php gen.php
php gen.php > /path/to/ciphersweet-py/tests/vectors/php_interop.json
```

`check_python_output.php` does the reverse: it decrypts a `py.json` written by Python
(see the docstring at the top of `tests/test_php_interop.py`) with the PHP library.
